# Jamm

Jamm est un coffre familial transfrontalier qui aide à organiser les documents importants et à préparer les démarches administratives au bon moment.

## Premier MVP

- Coffre de documents avec statut : prêt, à actualiser ou manquant
- Alerte de renouvellement de titre de séjour
- Checklist interactive pour préparer un dossier
- Préparation d'un dossier organisé, sans promesse juridique ni dépôt administratif
- Invitation familiale : prochaine étape

## Lancer localement

Ouvrez `index.html` dans un navigateur. Le MVP ne stocke aucune donnée réelle : il utilise un jeu de démonstration.

## Limites importantes

Jamm organise les pièces et oriente vers les démarches officielles. Il ne remplace pas l'administration, un avocat ou un conseil juridique, et ne garantit pas l'acceptation d'un dossier.
